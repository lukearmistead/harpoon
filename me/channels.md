# Channels

Where the sweep looks, and what it has learned about looking. Sweep-jobs
reads this every run and seeds it on the first one via a short interview about
the market. Lessons about a channel land here in the run that learns them,
dated: a board that died, a fund whose portfolio page moved, a seat category
that keeps failing the same criteria gate.

`me/criteria.md`, applied once in the main thread, never by the sourcing
